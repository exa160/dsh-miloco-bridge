# 习惯洞察

## 输入

1. `miloco_home_profile`：已有偏好、作息、习惯。
2. `miloco_perception_logs(limit=100)` / `miloco_event_list`：重复出现的时间与动作。
3. `miloco_task_list` + `miloco_rule_list` + `miloco_cron_list`：已经自动化的不要重复建议。
4. `miloco_device_list` / `miloco_device_spec`：确认建议的动作可执行。

## 筛选

一个习惯值得建议，需要同时满足：

- 至少重复出现两次，或用户明确说过
- 目前没有对应规则/任务
- 有明确可执行动作（开灯、提醒、播报、记录）
- 不会造成骚扰或隐私风险

## 输出

一次最多 3 条，每条包含：

```
现象：每天 22:00 左右客厅灯还亮着
证据：最近 5 天有 4 天如此
建议：22:30 提醒关灯，或直接关闭客厅灯
代价/风险：…
```

## 后续

- 用户同意 → 进入 `miloco-create-task` 流程，先查重再创建。
- 用户拒绝 → 不要重复建议；可在档案里记录“暂不需要”。
- 只读模式只给建议，不创建任务。
- 建议是一种打扰：没有足够证据时宁可不提。
