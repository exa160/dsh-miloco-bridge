# 感知摘要

## 输入

1. `miloco_perception_logs(limit=100)` 取近期感知日志。
2. `miloco_event_list(since, until, limit=300)` 取指定时间窗的原始事件。
3. 可选：`miloco_perception_engine_status()` 确认数据是否完整。
4. 可选：`miloco_device_list()` 把 did 映射成房间/设备名。

## 输出格式

```
# 家庭感知摘要 · YYYY-MM-DD

## 值得记住的事
- 时间 · 地点 · 发生了什么 · 涉及谁（仅在日志明确时）

## 日常节奏
- 起床/出门/回家/就寝等重复模式（只写有证据的）

## 异常与待确认
- 跌倒、长时间无人、异常声音、设备离线等；没有就写“无”

## 数据说明
- 覆盖时段、事件条数、缺失摄像头
```

## 规则

- 只写日志/事件里能支撑的内容；不补人物身份、不猜动机。
- 同一件事合并成一条，不复述每条原始事件。
- 涉及健康、安全、未成年人时用中性描述，不渲染。
- 摘要默认只回复给当前会话；要写入家庭档案必须走 `miloco-home-profile` 的候选写入流程，并让用户确认。
- 本技能不需要任何写工具；只读模式即可运行。
