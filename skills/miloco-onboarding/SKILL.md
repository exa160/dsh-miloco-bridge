# 家庭初始化

## 开始前

1. `miloco_status` 确认后端可达、账号已绑定。
2. `miloco_user_info` 看米家账号昵称与家庭成员。
3. `miloco_person_list` + `miloco_home_profile` 判断是否已经初始化。
4. `miloco_device_list` + `miloco_camera_list` 了解家里有什么。
5. `miloco_perception_engine_status` 看感知是否已开启。

## 访谈顺序

一次问一小块，不要一口气列十个问题：

1. **成员**：家里有哪些人？怎么称呼？各自家庭角色？
2. **作息**：大致起床/出门/回家/就寝时间。
3. **偏好**：饮食、温度、光线、娱乐偏好；过敏或健康注意事项（仅在用户愿意说时）。
4. **空间**：主要房间名称，是否有容易混淆的叫法。
5. **规则**：家里的约定，例如“孩子睡后客厅灯调暗”。
6. **宠物**：是否登记宠物；需要的话转到宠物登记流程。

## 写入

1. 成员用 `miloco_person_create(name, role)`。
2. 家庭知识用 `miloco_home_profile_write(ops)`，`source="user_told"`。
3. 空间/设备知识用 `space` / `device` 类型。
4. 不确定的内容先问，不写猜测。
5. 结束后 `miloco_home_profile_commit()`，再读一遍确认渲染正常。

## 收尾

- 告诉用户：感知范围、通知渠道、推送目标分别在哪里设置。
- 询问是否现在开启摄像头感知；开启需要用户明确同意。
- 不自动控制设备，不自动创建任务。
- 只读模式下只输出初始化清单，不写库。
